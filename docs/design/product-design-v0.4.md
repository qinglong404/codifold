# Codifold V0.4 — 新增功能与开发约定

## 1. 基础设计原则

Codifold 是将真实代码转换为中文语义逻辑视图的工具。

- AI 负责理解代码、划分语义块、生成结构化 JSON。
- 前端负责节点布局、自动连线、视图切换和镜头定位。
- 所有执行连线统一采用单箭头实线。
- 用户不直接编辑连线。
- 每个 JSON 文件对应一个独立视图。
- 使用数字 `id` 标识块，不再保留行列坐标。
- 所有块都保留中文名称、描述及源码映射。

## 2. 当前块类型

| 类型 | 作用 |
|---|---|
| `normal` | 普通行为块 |
| `branch` | 条件分支块 |
| `end` | 结束块 |
| `try` | 异常保护结构 |
| `catch` | 异常捕获处理 |
| `event_emit` | 事件发出 |
| `event_entry` | 事件处理入口 |

共七种类型。

其中 Try/Catch 的具体数据结构还需要进一步确定。

### 结束块

结束块只需满足：

**它的后面不自动生成执行连线。**

至于它代表结束程序、返回函数、结束回调还是退出某个逻辑范围，全部由中文名称和描述表达。

不需要额外定义固定的结束作用域枚举。

### 事件发出与事件入口

用于将事件的产生流程和处理流程拆开。

例如：

事件产生链：

`鼠标输入 → 命中测试 → 识别 Click → 事件发出`

事件处理链：

`事件入口 → 检查状态 → 执行运算 → 修改设备状态`

两个端点通过事件标识关联。

允许一对多，也允许只有事件入口而没有当前项目内的发出块。

事件注册和取消注册仍然用普通块描述，不新增专用块。

## 3. 自动连线

正常情况下，按 `blocks` 或 `steps` 数组顺序连接。

普通块可填写：

```json
"next": 12
```

其含义为跳转到编号 12，替换默认后继。

`next` 只能指定一个目标编号。

分支块通过 `branches` 中的条件和步骤列表表示不同执行路径。分支内部允许嵌套分支。

分支列表正常执行完毕后，继续外层序列的后续步骤。

结束块不产生后继执行连线。

## 4. 双击跳转

为所有块增加可选的 `jump` 字段。

当前视图跳转：

```json
"jump": {
  "id": 12
}
```

跨视图跳转：

```json
"jump": {
  "view": "motion_control",
  "id": 8
}
```

双击节点时：

1. 解析目标视图及块编号。
2. 如果目标在当前视图，直接聚焦。
3. 如果目标在其他视图，先切换视图。
4. 展开目标所在的折叠结构。
5. 移动镜头并聚焦目标。

`jump` 仅用于前端导航，不产生执行连线。

`next` 与 `jump` 必须严格区分。

## 5. 多视图管理

- 一个 JSON 对应一个视图。
- 启动时读取指定文件夹中的全部视图 JSON。
- 建立视图索引和块编号索引。
- 同一视图中的块 ID 唯一，不同视图可以使用相同编号。
- 跨视图引用需要同时指定目标视图和目标块。

建议增加稳定的 `view_id`，避免文件名变化破坏跳转关系。

## 6. AI 输出校验

AI 每次完成代码转换后，必须执行现有校验脚本。

目前的检查包括：

- JSON 与块字段语法是否合法。
- 引用的源代码文件是否存在。
- 代码行号和区间是否合法。
- 要求覆盖的代码是否全部被映射。
- 代码映射是否存在重复。

随着新功能开发，应补充：

- 块 ID 是否唯一。
- `next` 目标是否存在。
- `jump` 对应视图和块是否存在。
- 分支结构是否合法。
- 结束块是否错误产生后继。
- 事件引用及异常结构是否合法。

源码映射使用文件路径与行号，始终根据当前最新代码进行检查。

机器校验负责确定性规则；语义是否准确、抽象是否合理，仍需要独立判断。

## 7. 暂不扩展的内容

当前不急于设计：

- 更多专用节点类型。
- 完整并发时间线。
- 复杂事件调度系统。
- 反向代码生成协议。
- 所有语言异常机制的统一表示。

优先使用真实代码验证现有结构。只有出现表达不清晰、展示不美观或无法忠实表达代码的情况时，再修改设计。

## 8. 开发验收原则

每次新增功能至少检查：

1. 能否准确表达原始代码行为。
2. 是否有遗漏或错误的执行路径。
3. 是否符合 JSON 结构及自动连线规则。
4. 是否能够定位到真实源码。
5. 视图是否清晰、易读。
6. 跨视图导航是否准确。

**最终原则：AI 生成语义，Schema 约束结构，校验脚本检查确定性错误，前端统一负责展示。**
